# מבחני תרגול — סיעוד המבוגר חלק ב'

## מה יש כאן
| קובץ | תיאור |
|---|---|
| `מבחן_תרגול_סיעוד_המבוגר_ב.html` | **הקובץ היחיד שצריך כדי להתרגל.** עצמאי לגמרי — לוחצים פעמיים והוא נפתח בדפדפן. אין צורך באינטרנט. |
| `bank.json` | מחסן השאלות — 559 שאלות מתויגות לפי נושא |
| `build.py` | בונה מחדש את ה-HTML מתוך `bank.json` |

## איך מתרגלים
פותחים את קובץ ה-HTML → "התחל מבחן חדש" → 80 שאלות לפי חלוקת הנושאים של הקורס.
אחרי כל תשובה מוצג הנימוק; בסיום — ציון, פילוח לפי נושא וסקירה של השגויות.

**שאלה שכבר נשאלה לא תוגרל שוב.** ההיסטוריה נשמרת בדפדפן שבו פותחים את הקובץ
(לא בקובץ עצמו) — כך שדפדפן אחר או מחשב אחר מתחילים מאפס.
כפתור "איפוס היסטוריה" מנקה הכול ומחזיר את כל 559 השאלות למאגר.

יש חומר ל-**5 מבחנים מלאים ללא חזרה על אף שאלה** (הנושא המגביל: אונקולוגיה).

## להוסיף או לתקן שאלות
1. עורכים את `bank.json`. מבנה רשומה:
```json
{"n": 286, "t": "skin_burns", "q": "השאלה?", "o": ["מסיח 1","מסיח 2","מסיח 3","מסיח 4"],
 "a": 0, "e": "נימוק קצר", "g": "gen", "v": "מקור אימות", "flag": "verify"}
```
* `n` — מספר השאלה במסמך השחזורים המקורי (עוגן למקור)
* `t` — נושא: neuro · uro · ortho · nephro · hema · onco · immuno · skin_burns · ent · eye · breast
* `a` — אינדקס התשובה הנכונה במערך `o` (0–3)
* `g` — `orig` אם המסיחים מהשחזור, `gen` אם נוצרו
* `v` — מקור שאומת מולו (אופציונלי) · `flag` — סימון לבדיקה (אופציונלי)

2. מריצים:
```
python3 build.py מבחן_תרגול_סיעוד_המבוגר_ב.html
```
הבונה **נכשל בכוונה** אם מכסת נושא לא מתמלאת, אם יש פריט פגום או מסיחים כפולים —
כך שלא ייווצר קובץ מבחן שבור.

## הערות תוכן
* נוסחת הכוויות בכל הפריטים היא **ABA** (2 מ"ל × ק"ג × %TBSA; 4 מ"ל בכוויה חשמלית)
  לפי מצגת הקורס — לא פרקלנד.
* פריט 277 תוקן מול ברונר: קו ראשון ב-RA הוא **Methotrexate** (השחזור אמר אספירין).
* פריט 552 הוסר — השחזור סתר את ברונר בנושא גורמי ירידה בשמיעה.
* 10 פריטים מסומנים `flag: "verify"` — מנוסחים לפי הידע הקליני המקובל אך לא אומתו מול הספר.
