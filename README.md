# מלווה התנסות קלינית — סיעוד המבוגר א' · הסבה ט'

קובץ HTML יחיד (`index.html`) שמלווה את ההתנסות 04.10–14.11.2026. עובד אופליין, בלי שרת, בלי שליחת נתונים.

## שלב 1 (הגרסה הנוכחית)
- **בית:** שבוע ויום בהתנסות, שעות (שדה/סימולציה/סה"כ מול 168), מד היעדרות (סף 20%), כיסוי מיומנויות, כפתור "נוכח/ת היום" עם בחירת משמרת (נזכרת לפעם הבאה).
- **יומן:** רשומות נוכחות/היעדרות/השלמה, אישור היעדרות, חתימת מדריך/ה, תזכורות אחרי היעדרות, הדפסה במבנה נספח 4.
- **מיומנויות:** נספח 10 + תרגול מעבדה, 3 רמות (נצפה / בהדרכה / בפיקוח) עם תאריך, חיפוש, סינון, הדפסה לחתימה.
- **עוד:** טלפונים (חיוג ישיר), IPSG, תרופות בנות סיכון, 5 הרגעים, ISBAR, אירוע חריג, נהלים קריטיים, תיאום ציפיות (נספח 11), גיבוי, הגדרות.

עדכון לאפיון: "אבן הדרך הבאה" ו"משימות למשמרת הבאה" במסך הבית עברו לשלב 2.

## שמירה וגיבוי
- שמירה אוטומטית בדפדפן (localStorage) בכל שינוי.
- **עוד ← גיבוי ← שמור לקובץ** מוריד `clinical-backup-YYYY-MM-DD.json` (בטלפון — תפריט שיתוף ל-Drive/Files).
- **פתח קובץ** בודק את הקובץ, מציג סיכום (כולל רשומות לא תקינות שידולגו) ומחליף רק אחרי אישור; עותק של המצב הקודם נשמר במכשיר (`clinical.preimport`), ואפשר להחזיר אותו מ**עוד ← גיבוי ← החזר את העותק**.
- השמירה מתבצעת מיד כשהאפליקציה נסגרת או עוברת לרקע.
- אם הנתונים השמורים במכשיר לא נקראים, המקור נשמר בצד (`clinical.unreadable`) ומוצג באנר עם כפתור להורדתו.
- באנר תזכורת אם לא נשמר קובץ ב-3 ימים.

## התקנה בטלפון
פותחים את כתובת ה-GitHub Pages (פתיחה כ-`file://` לא שומרת נתונים באופן אמין ולא עובדת אופליין) ומתקינים:
- **אנדרואיד (Chrome):** כפתור "התקנה כאפליקציה" ב**עוד ← הגדרות**, או תפריט ⋮ ← "התקנת אפליקציה".
- **אייפון (Safari):** כפתור השיתוף ← "הוסף למסך הבית".

אחרי ההתקנה האפליקציה נפתחת גם בלי רשת (`sw.js`). אונליין תמיד נטענת הגרסה העדכנית; אם הרשת איטית מ-4 שניות — נפתח העותק האחרון.
מצב ההתקנה, העבודה בלי רשת ו"אחסון קבוע" מוצגים ב**עוד ← הגדרות ← אפליקציה בטלפון**.

**באייפון:** אפליקציה שהותקנה במסך הבית שומרת נתונים בנפרד מ-Safari. אם כבר רשמת נתונים ב-Safari: שומרים קובץ גיבוי ב-Safari ופותחים אותו מתוך האפליקציה (עוד ← גיבוי ← פתח קובץ).

## קבצים
- `index.html` — כל האפליקציה.
- `manifest.webmanifest`, `icons/` — שם ואייקונים להתקנה.
- `sw.js` — עבודה בלי רשת. בהוספה או הסרה של קבצים לרשימה `PRECACHE` יש להעלות את מספר הגרסה ב-`CACHE`.
- `.github/workflows/deploy-pages.yml` — מעלה את כל הקבצים האלה ל-GitHub Pages בכל push ל-main.

## עדכון תוכן
כל התוכן מהתדריך נמצא באובייקט `CONFIG` בראש הסקריפט: תאריכים, יעדי שעות, רמות מיומנות, רשימת המיומנויות, טלפונים ועוד.
מפתח מיומנות = `קטגוריה|שם המיומנות`, לכן שינוי נוסח של מיומנות קיימת ינתק את הסימון שלה.

## פרטיות
אין שדות מטופל בשלב 1. אין קריאות רשת מלבד טעינת האפליקציה עצמה מ-GitHub Pages, אין אנליטיקס, אין CDN. הנתונים לא יוצאים מהמכשיר.
